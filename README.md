# Operadores Aritméticos em JavaScript


Este repositório apresenta uma explicação simples e direta sobre **operadores aritméticos** em JavaScript, incluindo:

- Diferença entre `+` em **números** e **strings**  
- Operador de **exponenciação (`**`)**  
- Exemplos básicos e avançados  
- Uma **mini-calculadora** feita com HTML, CSS e JavaScript  
- Mini-desafio final para prática

---

## 📌 Operadores Aritméticos


| Operador | Descrição | Exemplo |
|---------|-----------|---------|
| `+` | Soma | `10 + 5 = 15` |
| `-` | Subtração | `10 - 5 = 5` |
| `*` | Multiplicação | `10 * 5 = 50` |
| `/` | Divisão | `10 / 2 = 5` |
| `%` | Resto da divisão | `10 % 3 = 1` |
| `**` | Exponenciação | `2 ** 3 = 8` |

---

## 📌 Diferença do operador `+` em números e strings

O operador `+` tem **duas funções**:

---

### ➤ 1. Soma numérica

```js
10 + 20 // 30

```

### ➤ 2. Concatenação (juntar textos)

Se qualquer lado for string, tudo vira string.

```js
"10" + 20   // "1020"
10 + "20"   // "1020"
"Olá " + "Mundo" // "Olá Mundo"

```
